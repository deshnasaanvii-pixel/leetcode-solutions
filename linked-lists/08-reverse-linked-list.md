# Reverse Linked List

**Problem:** Reverse a singly linked list.

**Approach:** Use `prev`, `curr`, and `next` pointers to reverse each link iteratively.

**Test Cases:**

* `1 → 2 → 3 → 4` → `4 → 3 → 2 → 1`
* `1` → `1`

**Time Complexity:** O(n)
**Space Complexity:** O(1)

**LeetCode:** [Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/)

**Result:** Accepted
