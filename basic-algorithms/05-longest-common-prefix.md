# Longest Common Prefix

**Problem:** Find the longest common prefix shared by all strings.

**Approach:** Compare characters at the same position across all strings until a mismatch occurs.

**Test Cases:**

* `["flower","flow","flight"]` → `"fl"`
* `["dog","racecar","car"]` → `""`

**Time Complexity:** O(n × m)
**Space Complexity:** O(m)

**LeetCode:** [Longest Common Prefix](https://leetcode.com/problems/longest-common-prefix/)
