# Binary Search

**Problem:** Search for a target value in a sorted array.

**Approach:** Repeatedly divide the search range into two halves using left, right and middle pointers.

**Test Cases:**

* `[1,3,5,7,9]`, target `7` → index `3`
* `[1,3,5,7,9]`, target `4` → `-1`

**Time Complexity:** O(log n)
**Space Complexity:** O(1)

**LeetCode:** [Binary Search](https://leetcode.com/problems/binary-search/)

**Result:** Accepted
