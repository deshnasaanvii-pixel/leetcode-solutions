# Reverse a String

**Problem:** Reverse an array of characters in-place.

**Approach:** Use two pointers from the beginning and end and swap characters until they meet.

**Test Cases:**

* `"hello"` → `"olleh"`
* `"a"` → `"a"`

**Time Complexity:** O(n)
**Space Complexity:** O(1)

**LeetCode:** [Reverse a String](https://leetcode.com/problems/reverse-string/)

**Result:** Accepted
