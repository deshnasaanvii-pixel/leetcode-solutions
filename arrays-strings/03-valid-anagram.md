# Valid Anagram

**Problem:** Determine whether two strings are anagrams.

**Approach:** Use a frequency array of size 26 to count characters.

**Test Cases:**

* `"anagram"`, `"nagaram"` → Anagram
* `"rat"`, `"car"` → Not Anagram

**Time Complexity:** O(n)
**Space Complexity:** O(1)

**LeetCode:** [Valid Anagram](https://leetcode.com/problems/valid-anagram/)

**Result:** Accepted
